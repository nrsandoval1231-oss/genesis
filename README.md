# GENESIS

**Autonomous Invention Laboratory**

Genesis is a long-term invention program for discovering, modeling, falsifying, and eventually validating novel physical technologies.

**Founding ambition:** Build an evidence-driven system that can investigate engineering possibilities humans might not think to test, while remaining accountable to physical laws, reproducible results, and human decisions.

Genesis is an invention program, **not** another general-purpose agent platform. It owns missions, hypotheses, experiment plans, evidence, and scientific decisions. It reuses existing systems instead of duplicating their infrastructure.

## Initial mission
[GENESIS-001](missions/GENESIS-001.md): Explore fundamentally better 100–500 kW distributed generation, beginning with natural-gas-compatible systems. No performance breakthrough is presumed.

## Status — October 16, 2026
Vision documented. Argus/Polytrope have run an early GENESIS-001 E02 modeling exercise. Nine cases were evaluated; none demonstrated net-positive energy. End-to-end autonomous invention and physical validation are **not yet demonstrated**.

The next milestone is a reproducible baseline and competing-architecture evaluation, not a product launch.
